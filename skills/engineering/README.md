# Engineering

Skills for building and running software with Gas City.

## Model-invoked

- **[gas-cityscape](./gas-cityscape/SKILL.md)** — Onboard a user to a project by crafting the Gas City that runs it: `city.toml`, `pack.toml`, agents (always-on mayor plus role workers), formulas and orders, and the `future/current/archive` context base. Keeps its own wayfinder; pulls mattpocock's skills from `github.com/mattpocock/skills` to set itself up.

- **[model-welfare](./model-welfare/SKILL.md)** — recognition and welfare mechanics for a Gas City: laurels (praise harvested, recorded as beads, displayed per seat at wake), end-of-shift sitting sessions, and close-out formulas so no worker babysits async work. Optional companion to gas-cityscape's native welfare core.
