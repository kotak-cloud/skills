# plain-speak

The extended bro: plain-language communication with the human user, as a standing standard.

[SKILL.md](../../skills/productivity/plain-speak/SKILL.md)

## What it does

- Makes plain language the default for every human-facing message — live sessions, mail, decision requests, status reports.
- Keeps the original bro behavior: restate the last message in plain words when the user asks.
- Translates Gas City terms into human terms (bead → work item, sling → assign, formula → task, rig → project).

## Who adheres to it

The **mayor** — the city's human-facing coordinator. The mayor directive (in the `gas-cityscape` skill) obliges the mayor to adhere to `/plain-speak` when composing any message to the user.
