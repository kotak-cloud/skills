# AGENTS.md

This repo is a skills catalog, maintained the way mattpocock/skills is.

## Layout

- Every skill lives at `skills/<category>/<name>/` with its `SKILL.md` at the top. Material the skill's agent must load sits inside the skill directory (`reference/`, `assets/`) — `SKILL.md` points at it, it does not inline it (progressive disclosure).
- `docs/engineering/<name>.md` is the human-facing docs page per skill.
- `.changeset/` holds pending change descriptions; `CHANGELOG.md` is generated by changesets and is never hand-edited.
- `scripts/link-skills.sh` symlinks every skill into `~/.claude/skills` and `~/.agents/skills` (maintainer flow); `scripts/list-skills.sh` lists them.

## Editing a skill

1. Edit the skill's `SKILL.md` and co-located files.
2. Add `.changeset/<topic>.md` describing the change (frontmatter `"kotak-cloud-skills": minor` unless the change is a plain bugfix — then `patch`).
3. Commit; the Release workflow opens the version PR.

## Conventions

- **Invocation**: the one skill here, `gas-cityscape`, is model-invoked — rich trigger phrasing in the `description` so the model reaches for it. See `.agents/invocation.md`.
- **Dependencies between skills** are expressed as `/skill`-style prose invocation ("Run the `/grilling` skill"), never cross-folder file links.
- **Prose is tight**: skills are instructions, not essays. Prefer checkable completion criteria over adjectives.
- No test suites or linters run in this repo — review the diff.
